# The Score Is the Product

Most shopping tools start with a text field.

You type a keyword. The index matches words. You get a list of links.

"Waxed cotton coat, midi or longer, natural lining or unlined, no synthetics, size M or L, under £500" is not a search query. It is a specification. No search box can hold it, and no keyword index can evaluate it consistently.

TailoredLoop starts from a different assumption. You describe your requirements once — material, length, lining, excluded materials, sizes, price ceiling. The system translates that structure into queries. You never write a query yourself.

The criteria come first. The queries follow.

---

The output of a run is not a list of links.

It is a score — 0 to 10 — for every candidate the system finds, against the same criteria, in the same run.

A product scored 8 satisfies the core criteria. A product scored 5 matched something meaningful but failed at least one requirement. Those numbers are comparable across every candidate, every run, over time.

Most tools leave the matching work to you: open the page, read the description, check the material, guess at sizing. TailoredLoop does that work explicitly, with a one-line explanation for each result — what matched and what did not.

A search engine returns relevance. TailoredLoop returns a judgment.

---

The honest answer to "who is this for?" is narrow.

TailoredLoop is not useful if you don't already know what you want. It does not help you refine vague taste. It does not surface trends.

It solves one problem: you know exactly what you want, you cannot find it, and no search engine can evaluate your criteria consistently across dozens of shops.

A waxed cotton coat with natural lining in size M under £500 is a real search. Done manually, it can take hours across a dozen sites. TailoredLoop makes it executable.

That specificity is a design choice, not a gap.

---

After you read results, you leave notes.

"Wrong material." "Doesn't ship to me." "Lining is synthetic despite the description."

You don't rewrite the configuration. You write in plain text, the way you'd explain it to a colleague.

On the next run, the system reads your notes across recent runs and distils them into refined scoring criteria. Shops with recurring problems get filtered out automatically. The search improves without you touching the specification.

The first run will not be perfect. Criteria you thought were sufficient may need context that only real results can reveal. Feedback is how that context gets captured.

---

The search configuration is private.

What you're looking for, how you've described it, what you've excluded — none of that is visible to anyone else.

But curated results can be made public. Any search can be promoted to the public results page: scored products, matched and unmatched criteria, the AI's explanation. Visitors can browse. They cannot run the search or change anything.

The public page is not a store. It is evidence that the system works.

Most discovery products blur the line between browsing and searching. TailoredLoop keeps them separate.
